## 批注样式与缩放更新（2026-10-23）

增加黄、绿、蓝、粉、橙、红、紫、黑八种高亮/文字颜色；文字字号范围 6–96 pt，文字框透明。选择文字批注后实时拖动或拉伸右下角手柄，抬起指针时写入一次撤销记录；取消手势或卸载时清理监听。百分比改为实际 PDF 渲染比例，范围 25%–400%，支持输入、−/+ 和适合宽度。原文和译文同步缩放；通过 Electron 的 Ctrl-wheel 事件处理触控板捏合，并保留鼠标附近的页面位置。

33 个 Vitest 测试（9 个文件）、类型检查和生产构建通过。新增测试覆盖多色批注与字号的保存/读回、FreeText 无背景色及可解析的默认文字样式、文字溢出拒绝保存、旧文字样式兼容、缩放上下限、滚轮单位换算、普通滚动不触发缩放、连续捏合事件合并，以及拉伸最小尺寸和页面边界。

独立 Vault `/tmp/Paper Lens Acceptance` / Obsidian 1.14.4 实测：绿色高亮，24 pt 红色中文两行批注，透明背景显示原蓝色线框，文字框从 240 × 60 拉伸至 360 × 120 PDF 单位，移动后一次撤销回到原位置，双击编辑弹窗、输入 150% 并放大、适合宽度、保存和关闭后重新打开。点击恢复后的文字批注，颜色和字号控件显示红色 / 24 pt，文字框尺寸保留。MuPDF 渲染保存文件并视觉确认绿色高亮、红色中文和背景透明；标准 FreeText 的 DA 为 24 pt 红色，未写背景色 C。PDF 文本选区仍自动出现在 Claudian 的 `1 line selected` 提示中。

真实触控板捏合硬件操作尚未复测：当前桌面自动化工具不提供捏合输入。Ctrl-wheel 事件路径由自动化测试验证，不能将其等同于硬件手势验收。复杂旋转批注、最低 Obsidian 版本及其他外部阅读器显示尚未复测。

## 翻译模型、权限与并行更新（2026-10-23）

工具栏增加逐 Agent 记忆的模型和推理强度选择、模型列表刷新及自定义 ID。Codex 使用 app-server `model/list`（含分页）；Claude 使用 SDK `supportedModels()`。目录不代表账号可调用权限。已知不支持图片的模型不能启动视觉审阅翻译；自定义模型由实际调用验证图片与 JSON schema 支持。

按用户确认的方案，翻译默认采用 Codex `approvalPolicy=never` / `sandbox=danger-full-access` 或 Claude `bypassPermissions` / `allowDangerouslySkipPermissions`，不修改全局配置。可在插件设置关闭。插件执行环境、提取、排版、校验与发布；Agent 生成术语、翻译和原文/译文图片对照审阅。默认两页并行，可选 1–4 页，复用环境、布局、术语表、片段译文和有效页面，串行更新清单及合并。失败视觉审阅最多修正三次后标记失败。取消会中断所有页面工作和工具进程，在退出前继续持有文档锁，防止新重试与旧发布争用清单。

41 个 Vitest 测试（12 个文件）、类型检查和生产构建通过。新增覆盖真实参数协议的替身检查（模型、effort、最高权限、自动批准、PNG 输入与结构化结果）、两页并行上限、独立页面会话继续、原文/译文双图输入、串行发布、有效检查点复用、片段 ID 完整性、三次审阅失败拒绝发布/合并、多工作取消、取消期间同文档互斥，以及工具错误输出和进程终止。Electron 定时器兼容已修复，避免浏览器返回数值 timer 时调用不存在的 `unref()`。
