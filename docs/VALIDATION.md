# 当前版本验收记录

版本：0.2.0。记录日期：2026-10-24。桌面环境：macOS、Obsidian 1.14.4。

## 自动化验证

本地测试位于 `dev/tests/`，不进入 Git 或插件包。验证命令和运行环境要求见 README。

- 56 项 Vitest 测试：API 地址与认证、模型目录、请求超时及取消、密钥脱敏、设置归一化、运行进程和完成协议、任务互斥、产物校验及移动恢复。
- PDF 和交互回归：批注保存与撤销、字体复用、外部修改冲突、排他输出、页内同步及独立滚动、缩放、连续自动高亮及选择完成事件。
- Python 适配层回归：产物发布、段落失败拦截、finish 后停止迭代、稀疏原生文字与扫描检测边界。真实引擎回归使用本地错误 API，无付费模型调用。
- 类型检查及生产打包通过；安装包仅包含插件代码、PDF.js、字体和 PDFMathTranslate 运行资源。

## 实际验收

- 独立测试 Vault 完成阅读、透明文字框移动和调整大小、连续高亮、换色、撤销、已有选区直接高亮、Esc 退出及 PDF 保存。保存读回确认批注颜色与坐标正确。
- 普通选择模式下，Claudian 收到 PDF 路径及选区，依据片段识别 Dataset Aurora、准确率 70%→82% 及增加 12 个百分点。
- 六页真实论文使用 gpt-6-luna / low、并发 4、关闭术语提取，复用已安装环境后总耗时 61.4 秒；页数和尺寸校验通过。第 1、3、5 页视觉检查确认段落翻译及图表主体保留，算法区域仍有小字号及断行问题。
- 稀疏原生文字的两页 PDF 使用 deepseek-v4.1-flash 实测成功交付，总耗时 21.8 秒。
- 51 页论文通过自定义模型服务完成翻译并保存；在 Vault 内移动到新目录后恢复 51/51 页，译文正常显示，未产生重复文件。
- 正式 Vault 的高亮工具及颜色控件已更新并重新加载；原文、译文和模型 API 配置保持完整。

## 结论边界

以上为具体样本和功能验收，不构成所有论文的成功率或速度保证。首次环境安装与模型下载耗时不计入复用环境的样本时间。结构校验及抽样视觉检查不代表全文语义、公式和排版已逐页审校。扫描 PDF 暂不支持。
